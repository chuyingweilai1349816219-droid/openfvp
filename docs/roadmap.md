## 阶段 0 的结论（决定后续工作量）

- VM 只有 **40 个 opcode**，且全是标准栈操作 —— 不需要结构分析复杂指令
- 引擎 API 只有 **148 条命令**，其中 **17 条本作未使用**，实际要写 **131 条**
- 命令表**内嵌在 `.hcb` 里**，id / 名字 / argc 全都是现成的，不需要结构分析分发函数

对比：openbgi 要实现的是 BGI 上千个操作码，FVP 的接口面小一个数量级。
