## 1. 一段话说清现状

引擎本体已经能**跑通两部目标作品**（`iroseka.hcb` / `Hoshimemo_HD.hcb`）：
脚本解释器与 Python 参考实现**逐字节一致**，渲染层与原版真值画面**平均差 5.4%**，

读档只能"部分恢复"（原版存档里没有 pc/栈）、影片跳、设置项大多只读、
引擎侧 UI 只做了标题菜单与一个游戏内菜单。
